# Active Brownian Particles

二维主动布朗粒子的模拟、参数扫描与不确定性估计。项目将作者 Fengrui Zhang 的原始 notebook 模块化为 Python 程序，提供完整实验入口和小参数示例。原项目由作者独立完成，不包含课程提供的代码，采用 [MIT License](LICENSE)。

Codex 协助本次命令行入口、小参数配置、输入校验与置信区间绘图的整理；核心模型与模拟函数来源于作者原始 notebook。

## 研究问题

模型描述二维恒速粒子，其方向受到旋转布朗噪声驱动：

```text
dx = v cos(phi) dt
dy = v sin(phi) dt
dphi = sqrt(2 D_R) dW_t
```

模型不包含额外平移噪声、外力或粒子相互作用。方向自相关、持续时间和长时间扩散系数的理论值分别为：

```text
C(t) = exp(-D_R |t|)
tau_R = 1 / D_R
D_eff = v^2 / (2 D_R)
```

代码比较这些关系与模拟统计量，展示短时弹道增长到长时扩散的过渡。这是经典模型的数值研究，不声称新的物理发现。

## 完整实验流程

`run.py` 编排以下步骤：

1. 五组旋转扩散率的方向自相关、指数拟合和整条记录 bootstrap；在 `D_R = 1` 处比较三个相关拟合窗口。
2. 七组速度/旋转扩散率组合的 MSD 与扩散系数拟合；在参考参数处比较替代拟合窗口与样本量子集。
3. 使用共享布朗路径比较嵌套时间步长，统计指定步长细化的差异与区间。
4. 拟合持续时间对旋转扩散率的对数标度指数及区间，保存数值摘要、配置、环境记录和两张主图。

输出包括 `summary.json`、运行使用的 `config.json`、`environment.json`、`data/` 中的数值档案，以及 `figures/` 中的主图。完整步长研究数组保存于 `data/coupled_step_study.npz`。`--no-plots` 仅跳过绘图，不跳过数值实验。

## 小参数与报告参数

小参数示例保留五个旋转扩散率和三个速度，合计五组方向自相关与七组 MSD 参数组合：

- 无量纲步长为 `h = D_R * dt = 0.05`。
- 自相关：每组 16 条记录，每条时长 `20 tau_R`，40 次整条记录 bootstrap。
- MSD：每组 256 条轨迹、8 个独立批次，时长 `20 tau_R`，在 `10–20 tau_R` 区间拟合扩散系数。
- 参考 MSD 的样本量子集为 64、128、256；替代窗口为 `[5, 15]`、`[10, 15]`、`[12, 20] tau_R`。
- 共享路径研究使用步长 `[0.2, 0.1, 0.02, 0.01, 0.005]`，128 条轨迹、8 批、时长 `20 tau_R`，记录间隔 `0.2 tau_R`，拟合窗口 `[10, 20] tau_R`。

这些是用于检查运行流程的演示参数，不代表原报告的采样精度。较少轨迹和 bootstrap 次数会使估计与区间不稳定，不能据此复述原报告精度或作研究结论。

`configs/report.json` 保留原配置：自相关每组 256 条记录、600 次 bootstrap；MSD 每组 16,384 条轨迹、64 个批次，并包含样本量、替代窗口和共享路径步长研究设置。**发布准备期间未重跑该报告配置，不声称完成原报告复现。**

## 方法与边界

- 位置积分使用每步起点的方向，角度采用高斯增量。
- 自相关使用零填充 FFT，避免循环卷绕，并按每个滞后的有效样本对数归一化。
- 指数拟合在原始相关值空间进行，持续时间保持正值。
- bootstrap 重采样整条独立记录，保留不同滞后之间的依赖。
- MSD 按独立轨迹批次保存；扩散系数与区间从批次估计得到，不把相关时间点当作独立样本。
- 绘图按置信区间中点及半宽绘制原始上下界，再单独标出点估计，避免 bootstrap 区间未包住点估计时出现负误差长度；没有裁剪区间或更改统计数据。
